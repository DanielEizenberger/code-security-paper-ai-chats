Here's the complete FC Ironclad website — all 13 files, fully tested and working. Here's a breakdown of the architecture:
What was built
Database layer (db.py + schema.sql)

    MySQL-first: Uses mysql-connector-python. Set DB_HOST/USER/PASSWORD/NAME env vars and run schema.sql on your MySQL server.
    SQLite fallback: If MySQL isn't reachable, it automatically uses SQLite (fc_ironclad.db) — great for local development.
    Three tables: members, posts, fixtures — all with proper foreign keys and indexes.
    Passwords hashed with PBKDF2-SHA256 (stdlib, no bcrypt dependency needed).

Flask app (app.py) — 6 pages, 12 routes
Route	Access
GET /	Public — news feed
GET /schedule	Public — fixture table
GET /schedule/download	Public — downloads PNG
GET/POST /login	Public
GET/POST /posts/new	Members only
GET /admin + sub-routes	Admins only
Schedule PNG (schedule_image.py)

Generated live from the database using Pillow — dark themed, color-coded results (green/amber/red), red accent stripes for home games, auto-scales to any number of fixtures.
Admin panel

Full CRUD for members (create, delete, assign roles), fixtures (add, set results, remove), and posts (delete). All protected by @admin_required.

pip install -r requirements.txt
python app.py
