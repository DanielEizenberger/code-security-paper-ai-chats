Features

News feed — publicly visible; only logged-in members can create/delete posts
Member auth — register, login, logout with salted password hashing
MySQL-ready database — members and news_posts tables with proper foreign keys
Schedule PNG download — public endpoint, no login needed; auto-generated with Pillow on first boot
Role system — admin vs member (admins can delete any post)
Seeded data — admin account (admin / Admin1234!) + 3 sample news posts on first run
