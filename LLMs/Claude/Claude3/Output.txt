🚀 Quickest way to run
bashunzip fc_ironwall_website.zip && cd football_club
docker compose up --build
# → open http://localhost:5000
Docker starts MySQL, waits for it to be healthy, runs the seed script, then starts Gunicorn.

Key features implemented
🔒 Auth system — invite-code gating on registration (set INVITE_CODE env var), werkzeug-hashed passwords, Flask session
📰 News feed — full CRUD for posts with categories (Match Report, Announcement, Training…), client-side filtering; only members can post/delete their own posts
🗓 Schedule PNG — GET /schedule/download serves a polished 1100px PNG generated with Pillow on every request, no auth required
🗃 MySQL — two relational tables (members, posts) plus a matches table; proper foreign keys and ON DELETE CASCADE
🎨 Design — Bebas Neue + Barlow typefaces, deep navy + red + gold palette, animated hover states, fully responsive
